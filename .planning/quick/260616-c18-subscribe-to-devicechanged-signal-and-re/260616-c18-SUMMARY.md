## Decisions Made

- **No notification on DeviceChanged:** The handler calls only `_scheduleRefresh()`. CapabilityDegraded is the correct channel for warnings; a benign AC-unplug present-port change should silently redraw the tile.
- **IFACE_XML placement:** DeviceChanged placed after DeviceRemoved / before CapabilityDegraded to match both XML copies and preserve the byte-equality invariant.
- **Structural source assertions in tests:** The `connectSignal` registration lives inside `_onAppeared`'s `UsbeehiveProxy` construction callback, which cannot be driven with fake proxies in bare gjs (no D-Bus). Source-level grep assertions via `GLib.file_get_contents` were used as the regression guard for the registration itself; behavioral assertions cover the handler contract.
- **TDD commit structure:** RED commit (test with `subscribedSignals`/`_debounceId via _emit` assertions that correctly failed) followed by GREEN commit (implementation + refined test assertions). Section 3 was reworked during GREEN to replace the unachievable proxy-interception approach with correct source-level and behavioral checks.

## Deviations from Plan

None — plan executed exactly as specified. The TDD cycle required iterating on test assertions in section 3 (the "handler registration check") because `UsbeehiveProxy` cannot be intercepted in bare gjs, but this was anticipated by the plan's style-(b) guidance and did not change the scope.

## Issues Encountered

- **GJS bare-test async limitation:** `_snapshotImmediate()` is `async`; a synchronous `check()` immediately after the call sees an empty `store.calls`. Resolved using top-level `await` (valid in GJS ESM modules), consistent with the test file already using ESM.
- **`UsbeehiveProxy` not interceptable in unit tests:** The `connectSignal` registration block is inside a closure that requires the real (or mocked) `UsbeehiveProxy` constructor to call back. Resolved with structural source-level assertions using `GLib.file_get_contents`.
