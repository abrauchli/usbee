## SHELL RESTART OUTSTANDING

**2.8.0 is on disk but not yet live.** The Shell is still running the
previously-loaded 2.7.1 code in memory. The new code loads only after a
GNOME Shell restart, which is the user's to perform:

- **Xorg:** `Alt+F2` → `r`
- **Wayland:** full log out and log back in

The executor deliberately did not attempt this — on Wayland it
terminates the session (and the agent with it); on Xorg it disrupts the
desktop without warning. The install is complete and correct regardless.

Corollary: nothing in this task was or could be verified by observing
the live popover or tile.

`"version` greps, the changelog heading grep, and the `wc -l`.
