<verification_convention>

Each check below ends in `&& echo SENTINEL` (or `|| echo SENTINEL` for
a negative assertion). This form behaves identically under bash and
fish, which matters because this host's shell is fish.

**A check passes only if its sentinel is printed.** A command that
prints nothing has FAILED — do not read a silent exit as success.

**Negative assertions use a two-step form.** Never pipe a `git`
command straight into a grep whose *failure* is the pass condition:
a pipeline reports only its last stage, so if `git` itself errors the
grep sees empty input, matches nothing, and the check falsely reports
clean. Instead, redirect `git` to a scratch file and require its own
`GIT-OK` sentinel first, then grep the file. Both sentinels must
print.

Scratch files go to `/tmp` (an allowed working directory); substitute
your session scratchpad if you prefer.

</verification_convention>
