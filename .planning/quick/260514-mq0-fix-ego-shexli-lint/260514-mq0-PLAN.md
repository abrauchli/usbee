# Fix EGO shexli Lint Errors

## Goal
Fix the 3 findings reported by `shexli` so the extension passes EGO review:
- EGO-P-001: schema id must start with `org.gnome.shell.extensions`
- EGO-P-002: schema path must start with `/org/gnome/shell/extensions`
- EGO-P-007: `src/forward-compat.test.js` must not be packed in the zip

## Must-haves
- Schema file renamed and content updated with correct id/path
- `metadata.json` `settings-schema` updated to match new schema id
- `src/forward-compat.test.js` moved outside the extension directory

## Tasks

### Task 1: Rename and update the GSettings schema file
- Rename `usbee@bitcreed.us/schemas/us.bitcreed.usbee.gschema.xml`
  → `usbee@bitcreed.us/schemas/org.gnome.shell.extensions.usbee.gschema.xml`
- Update `id` attribute: `us.bitcreed.usbee` → `org.gnome.shell.extensions.usbee`
- Update `path` attribute: `/us/bitcreed/usbee/` → `/org/gnome/shell/extensions/usbee/`

### Task 2: Update metadata.json
- Change `"settings-schema": "us.bitcreed.usbee"` → `"settings-schema": "org.gnome.shell.extensions.usbee"`

### Task 3: Move test file outside the extension directory
- Move `usbee@bitcreed.us/src/forward-compat.test.js` → `tests/forward-compat.test.js`
- Create `tests/` directory at repo root
