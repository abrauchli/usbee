## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| `gnome-extensions pack` missing `--extra-source` | Default pack omits `src/` and `icons/` subdirectories. Published zip is unusable (extension.js's first import fails). Surfaced during Plan 04-02 smoke test. | blocking | Plan 04-03 pack invocation MUST be `gnome-extensions pack --force --extra-source=src --extra-source=icons usbee@bitcreed.us`. Add an explicit verify step that lists the zip contents and grep for `usb-symbolic.svg` + `src/dbus-client.js` before tagging. |
| Module-load gettext | Calling `_(...)` at module top-level (e.g. inside a `const TABLE = new Map([['k', _('v')], …]);`) throws "gettext can only be called from extensions" because GJS's `#lookupExtension()` cannot find an Extension instance on the call stack before `enable()` runs. | advisory | Any gettext-wrapped const collection must be built lazily inside a function that is first invoked AFTER `enable()`. See `src/label-table.js` for the memoized pattern. |
| `St.BoxLayout` orientation enum | `orientation: Clutter.Orientation.VERTICAL` throws "No property orientation on StBoxLayout" on GNOME 46 baseline. | advisory | Use the legacy boolean `vertical: true/false` everywhere — it's universally supported on GNOME 46+. |
| `_setOpenedSubMenu` shim placement | `PopupSubMenuMenuItem.open()/close()` calls `_getTopMenu()._setOpenedSubMenu(...)`. `_getTopMenu()` walks up and stops at the FIRST `PopupMenuBase` delegate (e.g. a `PopupMenuSection`), not the QuickSettings menu further up. Either side may need shimming. | advisory | Shim `_setOpenedSubMenu` on BOTH `this.menu` AND `this._rowsSection` (the PopupMenuSection). See `src/tile.js` USBeeToggle constructor. |
| Extension-bundled icons not in iconName lookup | Adwaita does not ship a `usb-symbolic`; theme renders of `drive-removable-media-symbolic` look like "screen with ?" on some setups. | advisory | Use `gicon: Gio.icon_new_for_string(`${extension.path}/icons/foo.svg`)` instead of `iconName: 'foo'` to bypass theme lookup entirely. Pack invocation must include `--extra-source=icons`. |
