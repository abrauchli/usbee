## Decisions Made

1. **Unused `Gio` import removed from src/notifier.js.** RESEARCH §Code Example #1 included `import Gio from 'gi://Gio'` in the paste-quality skeleton, but the Notifier never references `Gio` directly (only `GLib`, `Main`, `MessageTray`, `gettext`). EGO reviewers and ESLint flag dead imports. Documented under "Deviations from Plan" below.

2. **Suppression-window hook on the re-entrant `_onAppeared` branch too.** The plan said "insert immediately after `setDaemonRunning(true);`" — there are two such sites: the cold-start proxy-construction callback AND the re-entrant `if (this._proxy !== null)` branch. A daemon restart while the extension stays loaded hits the re-entrant branch; without the hook the 2.5 s suppression would never arm. Symmetrical insertion is the correct reading.

3. **`gschemas.compiled` untracked.** Phase 1 inadvertently committed the compiled schema artifact. The plan's acceptance criteria require `git ls-files usbee@bitcreed.us/schemas/gschemas.compiled` to be empty, which was a Rule 1 / Rule 3 deviation (the previously-committed file blocked the criterion). Fixed by `git rm --cached` + new `.gitignore`.

4. **USBeeIndicator stores `this._extension` even though unused.** Plan said "Store `this._extension = extension;` on the indicator for symmetry (even if it never uses it directly — keeps the API consistent and gives Plan 02-02 a place to add prefs hooks without further constructor changes)." Followed verbatim.
